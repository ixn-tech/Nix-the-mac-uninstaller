# Nix — the Mac uninstaller

Nix removes macOS apps **and** the leftover files they scatter across your system — caches, preferences, logs, application-support folders, launch agents — then shows you exactly how much space you reclaimed.

## Requirements

- **macOS 14 (Sonoma) or later**
- Apple Silicon or Intel — universal build
- Signed with an Apple Developer ID and **notarized by Apple**

## Install

1. Download **Nix.dmg** above.
2. Open it and drag **Nix** into your **Applications** folder.
3. Launch Nix. To detect leftover files, grant **Full Disk Access** when prompted (System Settings → Privacy & Security → Full Disk Access).

Nix moves items to the **Trash** — nothing is permanently deleted, and you can restore anything until you empty it.
